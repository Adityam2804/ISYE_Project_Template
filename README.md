# ISE 2530 Course Project — Student Starter Repository

Welcome to the ISE 2530 course project.

This repository contains the starter materials for **Milestone 1**.

For this milestone, your team will select a dataset, understand what information it contains, define a recurring decision that the dataset can support, and evaluate whether the project is suitable for later milestones.

You do **not** need to build a database, perform advanced analysis, or create an application in Milestone 1.

---

## Milestone 1 Goal

The main question for Milestone 1 is:

> Can our selected dataset support a meaningful and realistic recurring decision?

By the end of this milestone, your team should be able to clearly explain:

- What dataset you selected
- What information the dataset contains
- Who would use the project
- What recurring decision the project will support
- What entity or object the decision is about
- What useful measures could eventually be calculated
- How the data could later be organized into relational tables
- What limitations exist in the dataset
- Whether the project is feasible for the rest of the course

## Working on the Project with GitHub Codespaces

For this project, you can work entirely through **GitHub Codespaces**.

GitHub Codespaces provides a browser-based version of VS Code connected directly to your team's GitHub repository. You do not need to install Python, Git, or VS Code on your personal computer to work on the project.

Each team member should use the same team repository but may open their own Codespace.

### Opening Your Project

1. Open your team's GitHub repository.
2. Click the green **Code** button.
3. Select **Codespaces**.
4. Click **Create codespace**.
5. Wait for the browser-based VS Code environment to open.

You can now edit the project files directly in your browser.

For Milestone 1, most of your work will involve editing the Markdown (`.md`) files inside:

```text
milestone_1/
```

### Saving and Sharing Your Work

All team members are working from the same GitHub repository. However, changes made inside your Codespace are not automatically shared with the rest of your team.

You will use three basic Git actions:

- **Pull** — get the latest changes made by your teammates
- **Commit** — save a version of your changes with a short description
- **Push** — send your committed changes to the team's GitHub repository

A good habit is:

```text
Pull → Edit → Save → Commit → Push
```

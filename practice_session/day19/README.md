# Day 19 Unified Practice — Decision Support Interface

One 30-minute practice combining the essential Part I ideas with Part II.

## Start
```bash
python practice_session/day19/setup_practice_db.py
streamlit run practice_session/day19/app.py
```

Open port 8501. Work only in `practice_session/day19/app.py`.

## 30-minute flow
- 0–2 min: setup
- Q1 (3 min): region control
- Q2 (3 min): cached connection
- Q3 (4 min): cached parameterized query
- Q4 (5 min): headline + chart + evidence table from one frame
- Q5 (4 min): filter the frame with a slider, no requery
- Q6 (3 min): Refresh button clears cached data
- Q7 (6 min): resupply recommendation + reasoning + limitation

Do not paste widget values into SQL text. Use `?` and `params`.
No commit/push is required during practice.
